For games/faro the user said (via the producer) not to be asked about UI details and that the bar is
commercial quality ("no me vengas con una mierda").

**Why:** they want finished, polished screens, not option menus to choose from.
**How to apply:** decide layouts, wording and tile art yourself; only escalate things that change
other agents' budgets or the GDD (VRAM slots, name lengths) as proposals in the report, with the
decision already taken in the mockups. See [[ui-language]], [[screen-gotchas]].
